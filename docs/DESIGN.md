# LyricVideo – design notes

Local macOS desktop app (Electron + React + TypeScript) for building Farsi
karaoke / lyric videos with Finglish transliteration, English translation and
cultural explanations, assisted by Claude.

## Decisions (agreed 2026-11-03)

| Topic | Decision |
|---|---|
| Shell | Electron desktop app. Renderer is React + Vite; all file, network and process work happens in the main process. |
| Media tools | `yt-dlp` and `ffmpeg` found on PATH / Homebrew. The app shows an install prompt when missing. |
| Claude access | Anthropic API key pasted into Settings, encrypted with Electron `safeStorage`, stored under the app's user-data folder. |
| Lyrics | Claude searches the web (server-side web search + fetch tools) and returns several candidates with source URLs; the user picks one or pastes lyrics manually. |
| Transliteration / translation | Both can be generated by Claude or found on the web as candidates. Finglish convention: `kh` for خ, `oo` for the long u sound, `aa` for long alef. Every cell stays editable. |
| Timing | Word-level. Automatic alignment runs first (Python sidecar: `faster-whisper` transcription in Farsi with word timestamps, then matched to the lyric words with a sequence alignment). The user then drags / nudges words and lines on the waveform. |
| Output | 1920x1080 MP4 rendered with ffmpeg. Style options in the app (fonts, colours, which scripts show, position, background). The original YouTube video can play as the background in both the in-app preview and the export. |
| Learning | Looping tools deferred. Per-line and whole-song explanations generated on demand and saved. |
| Project file | `.lvproj` is a zip: `project.json` + `audio.mp3` + `video.mp4` (when present) + background image. Fully offline once saved. |

## Pipeline

1. **Source** – import MP3, or paste a YouTube URL. `yt-dlp` downloads the best mp4 up to 1080p, `ffmpeg` extracts `audio.mp3`.
2. **Lyrics** – Claude agent searches for lyrics and returns candidates. User picks or pastes. Lines are split on newlines, words on whitespace.
3. **Text** – Claude generates per-word Finglish and per-line English (or fetches web candidates). Explanations generated per line and for the whole song.
4. **Align** – `resources/aligner/align.py` produces word timings; the editor lets the user fix them on a wavesurfer timeline synced with the video.
5. **Style & preview** – canvas renderer draws the frame from the project state. The same renderer is used for the export so what you see is what you get.
6. **Export** – the renderer produces one transparent PNG per distinct "state" (every time the highlighted word changes) plus a concat list with durations. ffmpeg overlays the PNG sequence on the background (video, image, or solid colour), muxes the audio, and writes the MP4.

## Process layout

```
src/main      Electron main: window, IPC handlers, settings, media, claude, aligner, exporter, project zip
src/preload   contextBridge API exposed as window.api
src/renderer  React UI (zustand store, wavesurfer timeline, canvas preview)
src/shared    Types shared across processes (Project, Line, Word, Style, IPC contracts)
resources/aligner  Python sidecar for automatic alignment
```

Project working copies live in `<userData>/projects/<id>/`. Saving zips that folder
into the chosen `.lvproj`; opening extracts into a fresh working folder.
The renderer reads media through the `media://` protocol, which maps to the working folder.
